# Static release

`release/static` is the only hosting input. It contains the entry point, aggregate study JSON, bundled JavaScript and CSS, security headers, license notices and a 404 page. The app uses hash paths so deep views work from the index. A top-level 404 makes missing files return an error. The local static verification server applies the same header values and simulates this missing-file behavior. [Cloudflare Pages routing](https://developers.cloudflare.com/pages/configuration/serving-pages/) · [Pages headers](https://developers.cloudflare.com/pages/configuration/headers/)

Cloudflare documents free and unlimited requests for assets that do not invoke a function. The export has zero Functions or Worker code. No storage bindings, AI services, metered compute, paid domain or API have been configured for this project. Pricing and account constraints should be rechecked for any authorized deployment. [Pages pricing](https://developers.cloudflare.com/pages/functions/pricing/) · [Pages limits](https://developers.cloudflare.com/pages/platform/limits/)

After written authorization of a target, use Cloudflare Pages static Direct Upload with the audited directory. Recheck the file hash manifest and target configuration immediately before uploading. Verify the index, hash views, missing asset status, headers and browser network requests at the resulting URL. The present release is prepared for local preview and external hosting remains undeployed.
