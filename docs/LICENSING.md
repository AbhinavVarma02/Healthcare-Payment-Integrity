# Source rights register

| Material | Source position | Project handling |
| --- | --- | --- |
| Eight CMS CERT CSVs and dictionaries | Each catalog distribution declares the USA.gov government-works URL. CSV and dictionary endpoints returned HTTP success without a sign-in or acceptance click | Analyze the CMS-origin control key, claim part, provider category and review decision locally. Retain raw downloads only in ignored storage. No raw or record-level redistribution |
| AMA CPT and procedure descriptions | CMS publishes a separate AMA copyright and license notice for covered material | Do not use or derive fields from the mixed procedure column. No CPT service group, descriptions, procedure-level model or redistribution |
| HCPCS Level II | The combined column includes heterogeneous code families | No use in this study |
| DRG, type of bill, X12, error codes | Outside the approved analysis contract | No code interpretation, modeling or redistribution |
| CMS payment benchmark candidates | Geography and Service products are public datasets containing procedure-keyed aggregates | Source review only. No benchmark downloads or merges |
| Research papers, guidance and reports | Publisher or agency sources | Cite and paraphrase. No bundled copies |

The USA.gov works policy distinguishes federal government material from third-party copyrighted material. Original code licensing covers original code. The publication review must assess aggregate cell size, identifiers, derived model access and third-party content before releasing any study artifact. See [verified sources](REFERENCES.md).
